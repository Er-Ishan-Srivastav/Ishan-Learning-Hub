❓ Getting Help

How to get your questions answered quickly!

✅

DO

  • Search existing answers first
  • Provide detailed context
  • Include error messages
  • Share Cassandra version
  • Describe what you've tried
  • Be patient and respectful
  • Follow up with solutions
  • Help others when you can
❌

DON'T

  • Ask "is anyone there?"
  • Post screenshots of text
  • Expect instant responses
  • Cross-post everywhere
  • Share production credentials
  • Demand immediate help
  • Ignore follow-up questions
  • Delete your questions

Great Question Template

Title: Brief description of problem

Context:
- Cassandra version: 4.1.3
- Cluster size: 6 nodes, RF=3
- Driver: Python 3.25

Problem:
Detailed description of what's happening

Expected: What should happen
Actual: What's actually happening

Error messages: (full stack trace)

What I've tried:
1. First attempt
2. Second attempt

Question: Specific question

🤝 How to Contribute

Everyone can contribute to Cassandra!

💻

Code Contributions

  • Fix bugs
  • Add features
  • Improve performance
  • Write tests

Start: Pick a "Low Hanging Fruit" ticket in JIRA

📖

Documentation

  • Fix typos
  • Add examples
  • Improve clarity
  • Translate docs

Easy entry point for first-time contributors!

🧪

Testing

  • Test new releases
  • Report bugs
  • Verify fixes
  • Performance testing

Critical for quality releases!

👥

Community Support

  • Answer questions
  • Write tutorials
  • Give presentations
  • Mentor newcomers

Help others learn Cassandra!

First Contribution Steps

  1. Join the dev mailing list
  2. Introduce yourself on Slack
  3. Read the contributor guide
  4. Find a "Low Hanging Fruit" ticket
  5. Comment on the ticket
  6. Submit your patch
  7. Work with reviewers
  8. Celebrate your first contribution! 🎉

💡 Community Tips
